# v0.0.2 — dependency and toolchain security refresh

> Publish via GitHub **Releases → Draft a new release → tag `v0.0.2` on `main`**. The
> release pipeline (multi-arch image, SBOM, CVE gate, cosign signing, and the two
> release-only conformance suites) triggers on release **publication**, not on tag push.

Maintenance release. No source changes — nothing under `internal/`, `cmd/`, or `pkg/`
differs from `v0.0.1`. The API surface, wire formats, and stored-data semantics are
unchanged, so this is a drop-in replacement.

## Security

- **Go toolchain go1.26.5 → go1.26.7**, clearing four standard-library advisories that
  `govulncheck` reported as reachable: [GO-2026-6090](https://pkg.go.dev/vuln/GO-2026-6090)
  (`crypto/tls` post-handshake message flood), [GO-2026-6089](https://pkg.go.dev/vuln/GO-2026-6089)
  (`net/http` `ReadHeaderTimeout` not applied to the h2c check),
  [GO-2026-6088](https://pkg.go.dev/vuln/GO-2026-6088) (`encoding/xml` unbounded decode
  recursion), and [GO-2026-5972](https://pkg.go.dev/vuln/GO-2026-5972) (`encoding/asn1`
  unbounded decode recursion).
- **`golang.org/x/text` v0.37.0 → v0.40.0**, clearing
  [GO-2026-5970](https://pkg.go.dev/vuln/GO-2026-5970) (infinite loop on invalid input),
  reachable through `pgxpool.NewWithConfig` → `norm.Form.Transform`.
- The `v0.0.1` image builder digest also resolved to go1.26.5, so published images carried
  that standard library. The builder digest now resolves to go1.26.7 and the release CVE
  gate (Grype, fail on HIGH) is clean — it reported six HIGH findings against the
  equivalent `v0.0.1`-era image.
- `govulncheck` reports **no vulnerabilities**; `gosec`, `golangci-lint`, `gitleaks`, and
  CodeQL are clean.

## Dependencies

- `prometheus/client_golang` 1.23.2 → 1.24.1, `stretchr/testify` 1.11.1 → 1.12.1,
  `testcontainers-go` 0.43.0 → 0.44.0 (plus transitives).
- 10 GitHub Actions bumped, all still pinned by commit SHA; `actions/setup-go`
  v6.5.0 → v7.0.0 is the only major (an ESM/dependency refresh — no input changes).
- `gcr.io/distroless/static:nonroot` runtime digest refreshed.

## Known limitation

Go 1.27 is **not** adopted. `golangci-lint` v2.12.2 panics in staticcheck's IR builder on a
1.27 toolchain and `gosec` v2.22.5 fails to load package types, so both gate tools must be
upgraded first. go1.26.7 already clears every advisory, so nothing security-relevant is
waiting on it.

See [`README.md`](../../README.md) for the API surface and [`docs/HIPAA_DEPLOYMENT.md`](../HIPAA_DEPLOYMENT.md)
for deployment hardening.
